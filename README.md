# 📈 Stock Agent

> AI 에이전트 기반 주식 분석 · 동향 분석 · 퀀트 서비스를 만드는 오픈 조직입니다.

우리는 LLM 에이전트가 시장 데이터를 스스로 수집·해석하고, 사람이 이해할 수 있는
인사이트로 바꿔주는 도구들을 만듭니다. 데이터 파이프라인부터 차트 UI, 퀀트 백테스트,
뉴스·공시 요약 에이전트까지 — 개인 투자자가 쓸 수 있는 형태로 묶는 것이 목표입니다.

## 무엇을 만드나요

- **📊 주식 분석** — 가격·재무·기술적 지표를 종합한 종목 리포트
- **📰 동향 분석** — 뉴스 · 공시 · 매크로(금리/환율)를 에이전트가 수집·요약
- **🤖 AI 에이전트** — 자연어로 묻고 답하는 리서치/스크리닝 어시스턴트
- **📐 퀀트** — 시그널 생성, 전략 백테스트, 포트폴리오 분석

## 핵심 가치

- **조회·분석 전용** — 자동 주문/매매가 아닌, 의사결정을 돕는 정보 제공에 집중합니다.
- **투명한 근거** — 에이전트의 결론에는 출처와 계산 과정을 함께 남깁니다.
- **개인 친화적** — 무거운 인프라 없이 개인이 직접 띄워 쓸 수 있는 구조를 지향합니다.
